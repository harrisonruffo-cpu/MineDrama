# 🌊 Litoral Novelas

Aplicativo Android desenvolvido em Jetpack Compose para streaming de mini novelas e dramas verticais com sincronização em nuvem via **Appwrite** e **Firebase Firestore/Storage**.

## ✨ Funcionalidades
- **Feed Vertical de Vídeos**: Player vertical imersivo estilo TikTok / Reels com rolagem contínua.
- **Catálogo Completo**: Capas em alta resolução, sinopses, classificação e contagem de episódios.
- **Nuvem Integrada**: Integração com Appwrite Cloud (Região NYC: `https://nyc.cloud.appwrite.io/v1`) e Firebase.
- **Painel de Publicação**: Upload de episódios MP4, capas, renomeação e organização.
- **Diagnóstico em Tempo Real**: Verificação rápida de conectividade e regras de segurança da nuvem.

## 🚀 Gerar APK no GitHub Actions
Vá para a aba **Actions** no repositório GitHub e execute o workflow **`Build & Release Litoral Novelas APK`**.
